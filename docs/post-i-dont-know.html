When an Agent Should Say “I Don’t Know”

5 min read · EMET Lab

Placeholder article, written to test the layout. The final text will replace it.

An agent that always has an answer is easy to build and hard to trust. The more useful skill is knowing when not to answer, or when to answer with a question.

“I don’t know” is not a failure. Said at the right moment, it is the most trustworthy thing an agent can say.

Uncertainty is a design choice

Whether an agent admits what it does not know is not an accident of the model. It is shaped by how the agent is set up, what it is rewarded for, and what its makers expect of it.

What good looks like

A good agent says what it knows, what it is guessing, and what would settle the question. It never invents a source to fill a gap. And it hands the decision back to a person when the stakes are high.
